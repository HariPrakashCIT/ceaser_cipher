                                                 Caesar Cipher CLI Tool
                                                 
                                                 Project Description:
                                                                     A command-line application that encrypts and decrypts messages using the Caesar cipher.
                                                 Technology Used:
                                                                C++
                                                 Features:
                                                          - Encrypts text by shifting letters through the alphabet
                                                          - Decrypts text by reversing the shift
                                                          - Preserves uppercase and lowercase letters
                                                          - Leaves spaces, numbers, and punctuation unchanged
                                                          - Accepts negative and large shift values
                                             
                                                What I Learned
 
                  String handling, character manipulation, modular arithmetic, input validation, and writing functions in C++.
